# ShopKart — Frontend Only

This package contains only the ShopKart frontend. No Java/Spring Boot or MySQL files are included.

## Features
- 120 unique generated products with unique image seeds
- Category filtering
- Search and sorting
- Auto-changing hero slider
- Product quick view
- Add to cart, quantity controls and persistent cart
- Wishlist with persistent storage
- Login and Sign Up working in frontend using browser localStorage
- Logout
- Responsive Flipkart/Myntra-style shopping UI
- Animations, hover effects and mobile layout

## Run
Open `index.html` in Chrome/Edge. Internet is required for the remote product/banner images.

## Note
Login/Signup in this frontend-only package is a demo implementation stored in the browser. It does not require a backend. For production authentication, connect the same UI to Spring Boot + MySQL later.
